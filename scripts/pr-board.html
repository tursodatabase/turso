Connect to GitHub

The board gets pull requests from the GitHub GraphQL API. This API needs a GitHub token.

  1. In a terminal, run this command of the GitHub CLI:
    gh auth token
  2. Paste the output of the command here and click Save.

The browser keeps the token in local storage. The page sends the token only to api.github.com.

If you do not use the GitHub CLI, make a classic token with no scopes. This token has read-only access to public data.
